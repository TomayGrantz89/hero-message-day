# Реализация значка рекламы в счетчике попыток

## Описание задачи
Добавить значок рекламы 🎬 в счетчик попыток получения предсказаний, чтобы пользователю было заметно, что есть еще одна попытка через просмотр рекламы.

## Внесенные изменения

### 1. HTML изменения (`src/app/pages/prediction/prediction.html`)
```html
<!-- Было -->
<div class="attempts">
  Осталось попыток: <span class="attempt-count">{{ attemptsRemaining }}</span>
</div>

<!-- Стало -->
<div class="attempts">
  Осталось попыток: <span class="attempt-count">{{ attemptsRemaining }}</span>
  <span class="ad-icon" 
        *ngIf="attemptsRemaining === 0 && attemptService.canWatchAd()"
        title="Получить ещё попытку через просмотр рекламы"
        (click)="showAdModal = true">
    🎬
  </span>
</div>
```

**Логика отображения:**
- Иконка показывается только при `attemptsRemaining === 0 && attemptService.canWatchAd()`
- При наведении показывается тултип с пояснением
- При клике открывается модальное окно с рекламой

## Логика работы

### Условия отображения иконки:
1. **Попытки = 0** (`attemptsRemaining === 0`)
2. **Реклама доступна** (`attemptService.canWatchAd() === true`)

### Поведение:
- **При наведении**: Показывается тултип "Получить ещё попытку через просмотр рекламы"
- **При клике**: Открывается модальное окно с рекламой (`showAdModal = true`)
- **Анимация**: Пульсирующая анимация для привлечения внимания
- **Ховер-эффект**: Увеличение иконки при наведении

## Тестовые сценарии

| Сценарий | Ожидаемый результат |
|----------|-------------------|
| Попытки > 0 | Иконка не отображается |
| Попытки = 0, реклама доступна | Иконка 🎬 отображается с анимацией |
| Попытки = 0, реклама просмотрена | Иконка не отображается |
| Клик по иконке | Открывается модальное окно с рекламой |
| Наведение на иконку | Показывается тултип с пояснением |

## Преимущества реализации

1. **Повышение заметности** - Анимированная иконка привлекает внимание пользователя к возможности получения дополнительной попытки
2. **Интуитивная понятность** - Иконка 🎬 ассоциируется с видео/рекламой
3. **Улучшение UX** - Пользователь сразу видит альтернативный способ получения попытки
4. **Минимальные изменения** - Не требуется изменения бизнес-логики, только представление
5. **Адаптивность** - Корректно отображается на всех размерах экранов
6. **Интерактивность** - Клик по иконке открывает модальное окно с рекламой

## Проверка работы

Для проверки работы необходимо:
1. Запустить приложение (`npm run start`)
2. Перейти на страницу предсказаний
3. Исчерпать все попытки (дождаться `attemptsRemaining === 0`)
4. Убедиться, что иконка 🎬 отображается рядом с счетчиком
5. Проверить анимацию и hover-эффекты
6. Проверить открытие модального окна при клике
